## 🚀 Utvalgte prosjekter

### 🌍 Atlas – Web-GIS for kriseberedskap (2026)
* **Teknologi:** MapLibre GL JS, JavaScript, PostGIS.
* **Beskrivelse:** Utviklet sentrale deler av en interaktiv beredskapsløsning med 3D-bygninger og terreng, filtrering, geosøk, ressursoversikt og rutevisning.
* **Resultat:** Mitt tekniske bidrag til kartløsningen og sluttpresentasjonen var sentralt i at teamet sikret seier i Expo Challenge.

### 🗄️ Kartverket NRL System – Database engineering (2025)
* **Teknologi:** SQL, MariaDB, C#, UML/ER.
* **Beskrivelse:** Designet og implementerte en relasjonsdatabase for rapportering og håndtering av luftfartshindre med rollebasert tilgang, datavalidering og sporbarhet.
* **Utførelse:** Arbeidet fra UML/ER-modellering og normalisering til SQL-spørringer og fysisk MariaDB-implementasjon, med fokus på integritet og skalerbarhet.

### 🌐 Globuskart – Geospatial visualisering (2026)
* **Teknologi:** Geodata, 3D, Azure, GitHub Actions.
* **Beskrivelse:** Bygget en interaktiv geospatial løsning for sanntidsdata, havnivåstigning og geografiske analyser, med 3D-visualisering og responsivt grensesnitt.
* **DevOps:** Satte opp publisering på Azure Static Web Apps og automatisert CI/CD via GitHub Actions.

### 💡 Flere prosjekter
* **Luksus Eiendom:** Medutviklet produktet fra konsept til levering med fokus på UX/UI, KI-integrasjon, responsiv frontend, kvalitetssikring og web-sikkerhet.
* **AI Lab / Parhesia:** Eksperimenterer med nye KI-verktøy, agentiske arbeidsflyter og prototyper. Parhesia utforsker data-intelligence for analyse og visualisering av beslutningsdata.
